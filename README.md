# BMP-Bioinformatics-Learning

> **一个面向 BMP 实验室同学的生物信息学学习与交流工具**
> 主要涵盖 **微生物组学、基因组学分析、机器学习方法** 等实用内容，旨在帮助大家快速入门并促进学术交流与合作。

---

## 📌 项目背景

随着实验产生的数据量日益增长，掌握 **生物信息学分析方法** 已成为研究中的必备技能。本仓库由 BMP 实验室同学共同维护，目标是：

- 为新入组的同学提供 **快速上手的学习路径**；
- 整理实验室常用的 **工具与脚本**；
- 搭建一个 **学习与交流的平台**，分享经验、解答疑惑。

---
